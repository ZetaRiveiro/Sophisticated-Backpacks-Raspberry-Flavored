# Sophisticated Backpacks: Raspberry Flavored Edition

A rebalanced fork of [Sophisticated Backpacks by p3pp3rf1y](https://github.com/p3pp3rf1y/SophisticatedBackpacks), specifically tuned to co-exist with the progression, design philosophy, and mechanics of the **Raspberry Flavored (RF)** modpack.

This fork trims down the bloat, respects vanilla-esque storage limitations, and prevents backpacks from trivializing core RF features such as Create automation, logistics, and alternative storage systems.

---

## Key Changes

### 1. Storage & Tier Rebalancing
* **Removed Tiers:** Diamond and Netherite backpacks have been completely removed due to massive inventory slots and upgrade capacity.
* **Loot Tables:** Removed backpacks from world-generation chest loot to ensure progression remains intentional.

---

### 2. Upgrade Pruning

To maintain mechanical balance and prevent overlapping with Raspberry Flavored features, most utility and advanced upgrades have been removed:

| Removed Upgrade | Reason for Removal |
| :--- | :--- |
| **Stack & Downgrade** | Exceeding the 64-item stack limit feels to "mody" and makes backpacks the single best storing option. |
| **All Advanced Upgrades** | Prevents backpacks from beeing overly reliable filters. |
| **Magnet / Void / Filter** | Redundant with RF magnet mechanics, trivializes contraptions, and undermines void/trash mechanics. |
| **Compacting** | Directly trivializes Create automation loops. |
| **Inception** | Obsoletes Terrabins and Sacks. |
| **Tank & Pump** | Liquids are hard to work with in RF, making this upgrade extremely unbalanced in RF. |
| **Feeding & Tool Swapper** | Brain dead upgrades lol. |
| **Smoking / Blasting** | Redudant due to RF removing or replacing these blocks. |
| **Stonecutter** | Redundant by the RF Sawing Table. |
| **Jukebox** | Rendered redundant by the Boombox item. |
| **Everlasting** | Redundant due to RF's death mechanics and void protection is useless with no End dimension. |
| **Battery / Experience** | EXP and LV/HV does not exist in RF. |
| **Anvil / Smithing** | This are just personal taste. I feel crafting and smelting are basic enough to be integrated into the backpack, but these two cross the line for me. |

#### **Retained Upgrades**
Only core quality-of-life utilities remain:
* Upgrade Base
* Crafting Upgrade
* Smelting Upgrade
* Refill Upgrade
* Deposit Upgrade
* Restock Upgrade
* Pickup Upgrade
