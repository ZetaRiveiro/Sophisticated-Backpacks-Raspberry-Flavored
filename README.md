# Sophisticated Backpacks: Raspberry Flavored Edition

A rebalanced fork of [Sophisticated Backpacks by p3pp3rf1y](https://github.com/p3pp3rf1y/SophisticatedBackpacks), specifically tuned to align with the progression, design philosophy, and mechanics of the **Raspberry Flavored (RF)** modpack.

This fork trims down the bloat, respects vanilla-esque storage limitations, and prevents backpacks from trivializing core RF features such as Create automation, logistics, and alternative storage systems.

---

## Key Changes

### 1. Storage & Tier Rebalancing
* **Removed Tiers:** Diamond and Netherite backpacks have been completely removed due to excessive inventory slots and upgrade capacity.
* **Loot Tables:** Removed backpacks from world-generation chest loot to ensure progression remains intentional.

---

### 2. Upgrade Pruning

To maintain mechanical balance and prevent overlapping with Raspberry Flavored features, most utility and advanced upgrades have been stripped:

| Removed Upgrade | Reason for Removal |
| :--- | :--- |
| **Stack & Downgrade** | Exceeding the 64-item stack limit invalidates vanilla-style storage management and makes backpacks single-handedly overpowered. |
| **All Advanced Upgrades** | Prevents backpacks from serving as overly reliable mobile filter systems or automated routing hubs. |
| **Magnet / Void / Filter** | Redundant with RF magnet mechanics, trivializes contraptions, and undermines void/trash mechanics. |
| **Compacting** | Directly trivializes Create automation loops. |
| **Inception** | Obsoletes Terrabins and Sacks. |
| **Tank & Pump** | Liquid management is intentionally constrained in RF; mobile fluid storage breaks progression balance. |
| **Feeding & Tool Swapper** | Automation features that remove active gameplay loops ("too brain dead"). |
| **Smoking / Blasting** | Unnecessary due to RF removing or replacing these mechanics. |
| **Stonecutter** | Outclassed by the RF Sawing Table. |
| **Jukebox** | Rendered redundant by the Boombox item. |
| **Everlasting** | Redundant due to RF's ghost-death mechanics; void protection is unneeded with no End dimension. |
| **Battery / Experience** | EXP and LV/HV systems do not exist in RF. |
| **Anvil / Smithing** | Personal balance decision—mobile crafting and smelting fit basic utility, but mobile repair/upgrading crosses the line. |

#### **Retained Upgrades**
Only core quality-of-life utilities remain:
* Upgrade Base
* Crafting Upgrade
* Smelting Upgrade
* Refill Upgrade
* Deposit Upgrade
* Restock Upgrade
* Pickup Upgrade
